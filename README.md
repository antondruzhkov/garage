# Гараж R nineT

3D-сервис для владельцев BMW R nineT: модель мотоцикла с настоящими передаточными, обслуживание по шагам прямо на 3D, официальный каталог BMW с номерами деталей, история ТО и «что пора сделать» по пробегу и дате. Один код работает как сайт и как Telegram Mini App.

- Сайт: https://antondruzhkov.github.io/garage/
- Бот: [@garage_r9t_bot](https://t.me/garage_r9t_bot) (кнопка меню «Открыть гараж»)

## Что внутри v1

- **Гараж**: 3D на весь экран, разделы Мотоцикл, Двигатель, Привод, Тормоза, Электрика, Приборка. Кнопки Вращение, Прозрачно, Разобрать/Собрать (долгое нажатие: ползунок). Тап по детали: шторка с названием, номером BMW, «В каталоге», «Операции». Двойной тап: общий вид раздела.
- **Обслуживание**: «что пора сделать» по регламенту BMW из r9t, операции с зонами (зелёная: проверь сам, жёлтая: сам с инструментом, красная: в сервис), шаги на 3D, кнопка «Сделал» пишет в историю.
- **Каталог**: 236 схем BMW K23, поиск по названию и номеру, «Показать на мотоцикле».
- **Кастом**: закрытый экран «скоро», сбор желающих.
- **Кабинет**: мой байк (цвет, номер, пробег), история ТО, фотоальбом, статус Pro, карточка «мой байк» 1080x1350.
- **Pro**: триал 14 дней после ввода пробега, экран цен (299 ₽/мес, 1 990 ₽/год), оплаты пока нет. Тест: `?pro=1`.

## Структура

```
web/                 сайт и Mini App (статикой на GitHub Pages)
  index.html         разметка
  style.css          стили: сначала телефон, на десктопе меню слева и шторки справа
  app.js             интерфейс: навигация, шторки, жесты, онбординг, обслуживание, каталог, кабинет, Pro, карточка, Telegram, track()
  store.js           хранение: Telegram CloudStorage (куски по 4000 символов) или localStorage
  config.js          номер Метрики, бот, цены, длина триала
  engine.js          3D-движок из -/r9t/index.html (модули E2, GBX, BAL, BELT, CLU, DRV не трогали), снаружи API window.R9T
  dash.js            приборка из r9t
  assets/            bike.wasm, catalog.json, three.min.js (r128), OrbitControls.js
docs/
  zadanie.md         задание v1
  NOTES.md           решения, заглушки, что уточнить
  BACKLOG.md         идеи после v1 (камера, кастом, синхронизация фото)
tests/
  e2e.mjs            Playwright: iPhone 390x844, десктоп 1440x900, эмуляция Telegram
  serve.mjs          статический сервер для тестов
.github/workflows/pages.yml   деплой web/ на Pages при push в main
```

Запуск локально: любой статический сервер из `web/`, например `npx serve web`. Тесты: `node tests/e2e.mjs shots all`.

## Данные

Только официальные данные BMW: каталог K23 и то, что уже собрано в r9t (инструкция владельца, схемы, регламент). Чего нет, интерфейс пишет «уточни по сервисной книжке BMW», список в `docs/NOTES.md`.

## Дальше: garage-server (закрытый репозиторий)

Сервера в v1 нет. Сюда приедет отдельный закрытый репозиторий `garage-server`:

- Telegram-бот (токен живёт только там): команды, уведомления;
- оплата Pro (Telegram Stars или ЮKassa), проверка подписи `initData`;
- напоминания о ТО по пробегу и дате;
- раздача файлов по https для `WebApp.downloadFile` (карточка «мой байк»);
- синхронизация истории и фото заказ-нарядов.

Клиент к этому готов: состояние в одном модуле `store`, события через `track()`, флаги Pro в `store.state.pro`, место под кастом `store.state.custom`.
