## Что уже есть
- r9t/index.html (~345 КБ, один файл): 3D-книга обслуживания BMW R nineT Scrambler (K23). three.js r128 (локально r9t/three.min.js, r9t/OrbitControls.js, фолбэк на CDN). Скан мотоцикла r9t/bike.wasm (gzip, свой формат чанков, читает loadBody, делит на детали relabel). Каталог BMW r9t/catalog.json (210 схем, таблица LINK связывает схемы с деталями).
- Внутренности построены руками и движутся с правильными передаточными: модули E2 (двигатель, цепи ГРМ), GBX (коробка, RATIOS, PRIMARY, FINAL), BAL (балансирный вал), BELT (ремень генератора), CLU (сцепление), DRV (кардан). Шестерни эвольвентные (invGear, meshAngle). ЭТИ МОДУЛИ НЕ ПЕРЕПИСЫВАТЬ.
- Разделы (табы #t-bike ... #t-cat): Мотоцикл, Двигатель, Привод, Тормоза, Электрика, Приборка, Обслуживание, Каталог. Кнопки в hud: ползунок Разобрать, Вращение, Прозрачно, Общий вид (#home). В Обслуживании пошаговые операции (curOp). В Каталоге «Показать на модели» (applyCatShow, catFocusView).
- Загрузчик: силуэт байка заполняется процентами, проверка WebGL, таймауты. Старт через queueMicrotask (иначе TDZ-падение).
- Номерная табличка: материалы LicPlate_* скана пропущены, вместо них пустая пластина ExtrudeGeometry в плоскости номера.

## Железные правила
- Репозиторий antondruzhkov/- не менять, только читать. Продукт живёт в antondruzhkov/garage: web/ (сайт и Mini App, один код), docs/ (план, задание, NOTES.md), README.md с описанием продукта и структуры. Файлы 3D (bike.wasm, catalog.json, three.min.js, OrbitControls.js) скопировать из -/r9t/ в web/assets/. Деплой web/ на GitHub Pages через GitHub Actions (.github/workflows/pages.yml). Сервера в v1 нет; бот, оплата и напоминания потом будут в отдельном закрытом репозитории garage-server, заложи под это место в README.

- Механика физична: детали не проходят сквозь валы и корпус, вращение с правильными передаточными. Ничего из этого не сломать.
- Весь текст интерфейса по-русски, коротко, без канцелярита. Длинное тире запрещено везде (и в коде, и в коммитах), только дефис.
- Перед каждым push: git pull --rebase (в репозитории работают другие сессии). Коммитить маленькими шагами, пушить после каждого рабочего шага.

## Что сделать (по порядку, каждый пункт довести до рабочего состояния и запушить)
1. Каркас web/: index.html + app.js + style.css. 3D-движок взять из -/r9t/index.html как есть (вынести в web/engine.js), переписать только интерфейс вокруг.
2. Мобильная раскладка (сначала 390x844, потом десктоп): шапка (номер, пробег, «до ТО N км»), лента разделов скроллом вбок (Мотоцикл, Двигатель, Привод, Тормоза, Электрика, Приборка), 3D на весь остаток, три круглые кнопки справа снизу (Вращение, Прозрачно, Разобрать/Собрать; ползунок разборки по долгому нажатию), нижнее меню: Гараж, Обслуживание, Каталог, Кастом, Кабинет. На десктопе меню слева, шторки панелью справа. Кнопку «Общий вид» убрать: каждый раздел сам открывается общим видом, двойной тап возвращает к нему. Кнопки не меньше 44 px, учесть safe-area.
3. Жесты: один палец крутит, два пальца зум и сдвиг (OrbitControls touches), тап по детали открывает шторку снизу (название, номер BMW из каталога, «В каталоге», «Операции»), двойной тап сбрасывает вид. Страница не должна скроллиться и зумиться под 3D (touch-action: none на canvas).
4. Первый запуск: после загрузки байк крутится, шторка «Это твой?»: модель (только Scrambler, остальные «скоро»), цвет (перекраска материалов бака и крашеных деталей: найди их по именам материалов скана; палитра 6 цветов плюс свой), номер (текст на CanvasTexture на пустой табличке), пробег, дата и пробег последнего ТО. Можно пропустить.
5. Хранение: один модуль store с двумя реализациями: Telegram.WebApp.CloudStorage внутри Telegram (лимит 4096 символов на значение, дели на ключи), localStorage в браузере. Все чтения и записи в try/catch.
6. Кабинет: мой байк (редактирование цвета, номера, пробега), история ТО (дата, пробег, что сделано, где, фото заказ-наряда сжатым превью в localStorage; в Telegram фото не хранить, написать «фото скоро»), статус Pro.
7. Обслуживание: сверху «что пора сделать» по пробегу и дате (интервалы только из того, что есть в r9t; нет данных, пиши как в правилах). Ниже список операций r9t, у каждой метка зоны: зелёная (проверь сам), жёлтая (сам, с инструментом и динамометрическим ключом), красная (не суйся, в сервис). Зону ставь осторожно, при сомнении красную. Операция открывается по шагам на 3D как в r9t; в конце кнопка «Сделал» пишет в историю. В каждой операции строка «Совет, не замена сервиса BMW. Сомневаешься, едь в сервис».
8. Каталог: поиск по названию и номеру, схемы по узлам, «Показать на мотоцикле» перекидывает в Гараж с подсветкой (используй готовые applyCatShow и LINK).
9. Триал и Pro: триал 14 дней стартует после ввода пробега. Бесплатно: 3D, разделы, кнопки, лампы приборки, первая операция целиком, схемы каталога без подсветки, 3 записи истории. Pro: всё остальное. Экран Pro: 299 ₽/мес или 1 990 ₽/год, кнопка «Хочу Pro» денег не берёт: пишет событие в аналитику и показывает «Записали. Оплата откроется скоро, продлим тебе триал до запуска». Для теста ?pro=1 в адресе.
10. Telegram Mini App: подключить https://telegram.org/js/telegram-web-app.js; если window.Telegram.WebApp.initData не пустой: ready(), expand(), disableVerticalSwipes() (иначе свайп по 3D закрывает приложение), цвета из themeParams, BackButton для шторок и экранов, HapticFeedback на кнопках, имя из initDataUnsafe.user в кабинете. Учесть contentSafeAreaInset. Вне Telegram всё работает как сайт.
11. Карточка «мой байк»: PNG 1080x1350 из снимка 3D (preserveDrawingBuffer или рендер в кадр) + номер, пробег, дата ТО, логотип «Гараж». В браузере navigator.share или скачивание; в Telegram скачивание через WebApp.downloadFile, если недоступно, показать картинку с подсказкой «зажми и сохрани».
12. Аналитика: события bike_added, mileage_set, service_logged, op_opened, op_done, cat_show, pro_wanted, card_shared, opened_in_telegram, custom_wanted.
13. Вкладка Кастом (закрыта, с замком): экран «Кастомайзинг скоро». Текст: оцифровываем кастомные детали для R nineT от производителей, примеришь их на свой байк в 3D до покупки. 3 карточки-заглушки (например, руль, выхлоп, зеркала) без брендов и чужих картинок, свои простые силуэты. Кнопка «Хочу кастом» пишет событие custom_wanted и показывает «Записали, позовём первым». Код примерки не писать, только заложить в store место под список установленных деталей (custom: []).

## Проверка перед каждым push
- Playwright Chromium, два прогона: iPhone (390x844, hasTouch, isMobile) и десктоп 1440x900. Если CDN недоступен, отдавай three.js локально через route. Ждать готовность модели, а не таймаут.
- Скриншот каждого экрана и каждого раздела, посмотреть глазами: ничего не обрезано, ничего не наезжает, кнопки не перекрывают байк.
- Консоль без ошибок. Пройти сценарий: первый запуск > цвет и номер видны на байке > операция > «Сделал» > запись в истории > перезагрузка > данные на месте.
- Эмулировать Telegram: подменить window.Telegram.WebApp заглушкой с initData и CloudStorage, пройти тот же сценарий.
- Сайт открывается по https://antondruzhkov.github.io/garage/ после деплоя Actions.
